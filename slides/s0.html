El viaje de una petición

  1. DNS traduce el nombre a una IP.
  2. Navegador pide el HTML (GET).
  3. Servidor responde el documento.
  4. El HTML revela CSS, fuentes e imágenes: se piden también.
  5. El navegador construye y pinta.
Restaurante: preguntar dirección (DNS), pedir el plato principal (HTML) y recibir acompañantes (CSS, imágenes) hasta servirse todo junto.

Reto de la sesión

  1. Nivel base: clona el sitio, corepack pnpm install, corepack pnpm dev, levántalo local. Trae 3 dudas escritas.
  2. Nivel reto: en DevTools > Network: número de peticiones, peso total y recurso dominante. Además: enumera las carpetas de src/ con una hipótesis cada una.
