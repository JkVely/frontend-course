S4 — JavaScript desde DevTools

Abre glud.org, presiona F12, pestaña Consola, y escribe:

document.title = "Tú mandas"

La pestaña cambió de nombre. Ningún programa externo hizo eso: lo ejecutaste tú, dentro del navegador. Hoy aprendemos a usar ese poder con intención.

PREGUNTA GUÍA: mostrar el poder inmediato de JS en el navegador. Pedir a un voluntario que ejecute el ejemplo y observe el cambio en la pestaña. Enfatizar que JS corre en la máquina del visitante, no en el servidor. Establecer tono de laboratorio: el navegador es el IDE.

Objetivos de la sesión

Al terminar vas a poder:

  1. Explicar qué es JavaScript y dónde se ejecuta.
  2. Usar la Consola de DevTools como laboratorio.
  3. Declarar variables const, let y usar tipos básicos.
  4. Acceder a elementos del DOM con querySelector.
  5. Modificar el DOM en tiempo real.
  6. Escuchar eventos con addEventListener.
  7. Leer errores y depurar con console.log.
Recorrer cada objetivo conectando con bloques siguientes. Resaltar que la consola es REPL y que dominio del navegador permite manipular página en vivo.

Funciones

Entrada → decisión → salida

  return "Hola, " + nombre
}
saludar("Mónica")

const despedirse = (nombre) => "Chao, " + nombre

Sin return la función devuelve undefined.

Ejercicio funciones

Código base

function formatearNombre(nombre) {
  const limpio = nombre.trim()
  return limpio.charAt(0).toUpperCase() + limpio.slice(1)
}
console.log(formatearNombre("  daniela "))
console.log(formatearNombre("  MÓNICA "))
Probar función, notar capitalización parcial. Preparar mejora.

Sintaxis avanzada

Rest parameters

function sumar(...valores) {
  return valores.reduce((ac, v) => ac + v, 0);
}
console.log(sumar(1, 2, 3, 4));
Explicar rest para capturar argumentos indeterminados.

Sintaxis avanzada
